# 使用说明

<p align="right"><a href="./使用说明.md">🇨🇳 简体中文</a> · <a href="./USAGE.md">🇺🇸 English</a></p>

这是预发布软件。首次使用前，请通过你正常的电脑备份方式备份自己的 Codex 配置。

## 从源码安装

前提条件：

- 当前桌面用户已安装 Codex。
- Python 3.11 或更高版本。
- 执行切换前必须彻底退出 Codex。

```bash
python -m pip install .
codex-mode-switcher gui
```

也可以运行 `codex-mode-switcher --help` 使用命令行。

## 严格隐私模式流程

1. 使用个人账号登录时，先执行一次“保存账号配置”。工具只保存非认证配置，不读取、不复制账号认证信息。
2. 准备只包含一个 Provider 表、且不含任何凭据的 TOML 文件，并导入为 API Profile。
3. 点击“预览所选项”。界面只展示将被修改的设置名称，不展示服务地址。
4. 完全退出 Codex 后，点击“启用所选 API”，在一次性输入框中输入 API Key。
5. 如果 Codex 的 API 模式要求当前认证文件，Key 只会写入该活动位置；本工具不会保存 Profile 副本、不会备份 Key，也不会联网发送。
6. 返回个人账号时，先完全退出 Codex，点击“返回账号”。工具会恢复已保存的非认证配置并删除活动 API 认证；然后你直接在 Codex 中登录。

## API 配置示例

```toml
model = "your-model"

[model_providers.example]
base_url = "https://api.example.invalid/v1"
wire_api = "responses"
```

不要把 API Key、Token、Authorization Header、密码、包含账号密码的 URL 或带凭据的查询参数放进这个文件。工具会拒绝常见的敏感字段和格式。

## 本工具会改什么

启用 API 时，会修改当前 Codex 的 `config.toml`，以及仅在 API 模式需要时修改当前认证文件。返回账号时，会恢复已保存的非认证配置，并删除活动 API 认证文件。

工具不会自动启动 Codex。这样用户可以先检查结果，再自行启动客户端。

## 清理本机数据

请先回到账号模式，再删除本机状态目录：

- macOS：`~/Library/Application Support/Codex Mode Switcher`
- Windows：`%LOCALAPPDATA%\Codex Mode Switcher`
- Linux：`$XDG_STATE_HOME/codex-mode-switcher`，或 `~/.local/state/codex-mode-switcher`

这会删除本工具保存的 Profile 模板和账号配置，不会卸载 Codex，也无法改变 API 服务商自身的数据保留策略。
